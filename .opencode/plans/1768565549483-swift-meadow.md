# Plan: Setup ZoomToText with uv

## Objective
Set up the ZoomToText project using `uv` package manager with a virtual environment, installing all dependencies including PyTorch with CUDA 13.0 support.

## Configuration
- **PyTorch**: CUDA 13.0 (cu130) from https://download.pytorch.org/whl/cu130
- **Optional features**: dev, live, gui, summarizers (all)

## Steps

### Step 1: Install uv (if not already installed)
```powershell
# Option A: Using pip
pip install uv

# Option B: Using PowerShell installer (recommended)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### Step 2: Create virtual environment with uv
```powershell
uv venv --python 3.10
```

### Step 3: Activate the virtual environment
```powershell
.venv\Scripts\activate
```

### Step 4: Install FFmpeg (system requirement)
FFmpeg is required by Whisper for audio processing. Install via:
```powershell
winget install -e --id Gyan.FFmpeg
```
Verify with: `ffmpeg -version`

### Step 5: Install PyTorch with CUDA 13.0 support
PyTorch must be installed first (before the project) since openai-whisper depends on it:
```powershell
uv pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
```

### Step 6: Install the project with all optional dependencies
```powershell
uv pip install ".[dev,live,gui,summarizers]"
```

## Alternative: Using pyproject.toml with uv sources (Advanced)

For a more integrated approach, you could modify pyproject.toml to include uv-specific index configuration:

Add to pyproject.toml:
```toml
[tool.uv.sources]
torch = { index = "pytorch-cu130" }
torchvision = { index = "pytorch-cu130" }
torchaudio = { index = "pytorch-cu130" }

[[tool.uv.index]]
name = "pytorch-cu130"
url = "https://download.pytorch.org/whl/cu130"
explicit = true
```

Then install with:
```powershell
uv sync --extra dev --extra live --extra gui --extra summarizers
```

## Verification

1. **Check PyTorch CUDA**:
   ```powershell
   python -c "import torch; print(f'CUDA available: {torch.cuda.is_available()}')"
   ```

2. **Check CLI works**:
   ```powershell
   python -m zoom_to_text.cli --help
   ```

3. **List audio devices**:
   ```powershell
   python -m zoom_to_text.cli --list-devices
   ```

4. **Run tests**:
   ```powershell
   pytest -q
   ```

## Files Modified
None - this is a setup-only plan using existing project configuration.

## Notes
- Windows-only project (uses Windows loopback audio capture)
- FFmpeg must be on PATH
- The `soundcard` package (included in `live` extra) enables live audio capture at 48 kHz
